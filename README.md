## 🚀 Something I've been building

### Bright Prints

A personalised printing platform built to make ordering customised products easier.

This has been one of my favourite projects because it takes a real-world business process and turns it into something much more streamlined.

A few things I've worked on:
- Configurable product templates and dynamic text scaling.
- Live previews so customers can see their designs before ordering.
- Automated, production-ready PDF generation.
- File storage and signed URLs using Cloudflare R2.
- Helping increase daily order capacity from around 20 to 40 orders.

**Built with:** TypeScript, Next.js, MongoDB, Payload CMS and Cloudflare R2.
